# 电力一次系统图（单线图）符号规格

> 这份文档是电力域包的**记法依据**：符号画成什么样、为什么这么画、每个符号旁写什么文字符号，
> 都能在这里对回来源。实现见 `src/power/power_shapes.ts`，规格测试见 `tests/power/power-symbols.test.ts`，
> 可视化图例见 `examples/power-symbols.html`。

## 1. 依据的标准

| 标准 | 用途 | 本包怎么用 |
|---|---|---|
| **JB/T 5872-1991《高压开关设备电气图形及文字符号》** | 额定电压 3kV 及以上高压开关设备的图形符号与文字符号 | 断路器 / 隔离开关 / 负荷开关 / 接地开关 / 互感器 / 变压器 / 熔断器 / 避雷器 / 电抗器 / 接地等符号的形状与文字符号，逐个对照该标准的图例实现 |
| **GB/T 4728 系列《电气简图用图形符号》**（等同采用 IEC 60617） | 通用图形符号体系；第 7 部分为「开关、控制和保护器件」 | 通用规则：导线 / 母线的画法、开关电器**按无激励、无外力的「正常状态」绘制**（本包默认画断开态） |
| **SD 240-87《电力系统部分设备统一编号准则》** | 设备**调度编号**（命名）：发电机 F、变压器 L、母线 M、断路器 K、刀闸 D、线路 XL、电流互感器 LH、电压互感器 YH… | 与图形符号**不同层**：本包用 `tag`（图形符号旁的文字符号）表达图纸口径，设备名/调度编号走数据字段（`name` / `dispatchNo`），两者不混用 |

## 2. 符号表（本包已实现）

文字符号取**图纸口径**（JB/T 5872 / GB/T 7159），括号里是 SD 240-87 的调度编号口径对照。

| kind | 名称 | 文字符号 | 构成要素（可辨识特征） | 调度编号口径 |
|---|---|---|---|---|
| `busbar` | 母线 | W | 加粗实线（比其它符号线宽粗） | M（母线） |
| `breaker` | 断路器 | QF | 上端引线 + **灭弧叉（×）** + 斜刀臂 + 下端引线 | K |
| `disconnector` | 隔离开关 | QS | 上端引线 + **静触头横杠（T 形可见断口）** + 斜刀臂 + 下端引线 | D |
| `loadSwitch` | 负荷开关 | QL | 隔离开关记法 + **顶端空心小圆** | — |
| `earthingSwitch` | 接地开关 | QE | 开关本体 + **接地符号（三条递减横线）** | — |
| `earth` | 接地 | E | 竖线 + 三条递减横线 | — |
| `currentTransformer` | 电流互感器 | TA | 导线**穿过圆** + 圆侧电流方向折线 | LH |
| `voltageTransformer` | 电压互感器 | TV | **两个上下相扣的圆**（一次 / 二次绕组） | YH |
| `transformer` | 变压器 | TM | 两个相扣圆 + 圈内绕组联结标记（上 △ 下 Y = 星-三角） | L |
| `fuse` | 熔断器 | FU | 细长矩形套在导线上 | — |
| `arrester` | 避雷器 | F | 矩形 + 内部**放电箭头** | BL |
| `reactor` | 电抗器 | L | 线圈（半圆弧） | DK |
| `generator` | 发电机 | G | 圆 + 圆内字母 G | F |
| `motor` | 电动机 | M | 圆 + 圆内字母 M | — |
| `load` | 负荷 / 出线 | — | 向下箭头（GB/T 4728 的电能输出方向记法） | XL（线路） |

## 3. 外观统一（硬要求）

`POWER_STYLE` 里集中定义，所有符号共用：

- 描边色 `#1f2937`（近黑石板色，不用纯黑：缩放与打印都不刺眼）；
- 线宽 `1.6`；母线 / 接地这类加粗元素用 `3`（`heavyLineWidth`）；
- 文字符号统一放**符号右下角**，字号 `10`、颜色 `#475569`；
- 圆内字母（G / M）统一字号 `15`，居中；
- 串联设备（断路器 / 隔离开关 / 互感器 / 熔断器…）的接线端子统一在**上下（T / B）**；
- 所有空心元件用**白色填充**（不是 `'none'`：引擎按 canvas 颜色解析，非法值会退回上一次的填充色 —— 实测踩过「空心圆变成实心红」）。

## 4. 默认值（已按这套实现，可覆盖）

以下五条是**本包采用的默认口径**；需要贴合某家公司规范时，改配置即可，不用改代码。

1. **电压等级色标**：默认 500kV 淡黄 / 220kV 紫 / 110kV 朱红 / 35kV 鲜黄 / 10kV 绛红 / 6kV 深蓝
   （来源：公开资料《电力系统电压等级颜色》；hex 是按颜色名取的**近似值**）。
   各电网公司规范不统一 → 用 `designer.setVoltageColors({ '110kV': '#xxxxxx' })` 覆盖。
2. **文字符号口径**：**图纸口径**（QF / QS / QL / QE / TA / TV / TM / …）。
   调度编号（K / D / M / LH / YH…）属于设备命名，放在 `name` / 业务字段里，两者不混用。
3. **开关运行态**：`switchState` 驱动**刀臂形状**（`open` = 标准断开态斜刀臂；`closed` = 竖直合闸）
   + **状态标签（分 / 合）**。静态图纸只画标准断开态；SCADA 式画面用运行态。
4. **电抗器**：采用线圈记法（两段半圆弧 + 引线），与「消弧线圈」同一套画法。
5. **三相表示法**：暂未出图（单线图 + 三条斜线的记法）；等有真实图纸需求时再补。

## 5. 运行态与拓扑（应用层）

- 颜色优先级：**明确不带电 → 灰（`#94a3b8`）**；否则按电压等级色标；没标等级用中性描边色。
  静态图纸（没算拓扑）与 SCADA 式画面（算过拓扑）因此共用一套代码，差别只在 `energized` 有没有被赋值。
- 带电范围：从**电源点**（`energizedSource`）出发做 BFS，只有**合位的开关**允许电流继续往外走；
  分位的开关自身仍算带电（一端接电源）。
- 电气连通域：按「开关全合」算，用于结构检查（如「这条母线所在连通域里有没有电源」）。
- **五防相关的两条校验**（error 级）：带电合接地刀闸、带接地线合闸送电。
  完整五防还需要操作票 / 锁具 / 时序信息，本包只做得了**由当前接线与开关状态能判定的部分**。

## 6. 已知限制

1. ~~母线「T 接」的连接点~~ **已解决（2026-09-12，IED 0.0.33）**：不改引擎，改成
   **`attachedBusId` + 几何贴合 + 应用层位移传播**——挂在母线上的设备记一个 `attachedBusId`，
   顶部引线贴住母线中心线；拓扑把「记录指向这条母线 **且** 几何仍然贴合」当成隐式等电位，
   把设备拖开就自动断开。拖动母线时由应用层把挂上去的设备一起平移（导体本来就会跟随宿主，整条间隔跟着走）。
   评估与备选方案见 `ice-render/docs/architecture/16-link-port-evaluation.md`。
   ⚠️ 期间实测到一条硬约束：**「把设备收成母线的子节点」这条路走不通**——复合组件
   （`hasDerivedChildren() === true`）的子节点会被序列化器整体跳过，快照里 23 台设备会掉成 15 台。
   要真做嵌套，得引擎先提供「只序列化真实子节点」的钩子（见 16 号文档的后续项）。
2. **案例的排布是手工给的**：工程实际图纸的间隔顺序、间距有设计习惯（比如按电压等级分排），
   本包还没有自动布局；等有了真实图纸样例再补。
3. **电压等级色标的 hex 是近似值**：颜色名来自公开资料，具体色号各公司不同，用配置覆盖。
