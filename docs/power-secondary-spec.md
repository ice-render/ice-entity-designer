# 电力二次回路（保护 / 电流电压回路 / 端子排）规格

> 这是**二次侧域包**的记法依据与范围说明，和 [电力一次系统图规格](power-symbol-spec.md) 配套。
> 二次图不是「多几个符号」——它是**另一种图**：一次图是单线图（一条线 = 三相），
> 二次图是**回路图**（一条线 = 一个具体回路，带回路编号、端子号、电缆编号）。
> 本轮先做**简化版第一刀**：保护电流回路 + 端子排这一条链路。

## 1. 图种（二次图纸的分类）

依据公开教材《典型二次回路图解》（92 页，含图 3-2 / 3-3 / 7-1 / 7-2 等真实图样）：

| 图种 | 内容 | 本轮范围 |
|---|---|---|
| **交流电流 / 电压回路图** | 互感器二次绕组 → 电缆 → 端子排 → 保护/测量装置；带回路编号 | ✅ **第一刀做这个** |
| **控制 / 操作回路图** | 合闸、跳闸、防跳、闭锁、储能；含接点逻辑 | ⏳ 下一步（规则更绕） |
| **信号 / 开入回路图** | 开关量采集、光字牌 | ⏳ 下一步 |
| **端子排与电缆联系图** | 端子号成列、电缆两端对应（**表格型布局**） | ✅ 第一刀做端子排（简化形态） |
| 智能站 GOOSE / SV 虚端子 | 数字化站的虚回路 | ❌ 本轮不做（需要另外的参考资料） |

## 2. 二次图的文字符号体系（与一次侧不同！）

一次侧用 **QF / QS / QE / TA / TV…**（JB/T 5872）；
二次侧主流用 **IEEE C37.2 功能编号**（教材表 5-1 的真实用法）：

| 编号 | 含义 | 编号 | 含义 |
|---|---|---|---|
| `52` | 断路器 | `52a` / `52b` | 断路器辅助接点（常开 / 常闭） |
| `43` / `43LR` | 切换开关（远方 / 就地） | `52Y` | 防跳继电器 |
| `88` / `88M` | 辅助继电器 / 储能电机接触器 | `49` / `49M` | 过流继电器 |
| `33` / `33hb` | 位置开关 / 弹簧储能限位开关 | `63` / `63GL` | 压力（SF₆ 气压）接点 |
| `8` | 电源控制（合闸/储能电源投入） | `11` | 操作按钮（合闸/分闸） |

> 本包的做法与一次侧一致：**功能编号放进 `tag`（元件旁的文字符号）**，设备名/型号走数据字段。

## 3. 回路编号与端子（二次图区别于一次图的关键）

来自教材图 7-2（110kV 线路保护电流回路接线图）的真实写法：

- **回路编号**：`A411 / B411 / C411 / N411` —— 等电位原则：同一电位的所有导线用同一个编号；
  A/B/C 表示相别，数字段表示回路类别（411 属电流回路），N 为中性线；接地画在 N 侧。
- **端子号**：`201～208` 成列排在端子排上，左边接现场（电缆侧）、右边接屏柜（装置侧）。
- **电缆编号**：`1D1 / 1D2 / 1D3 / 1D5 / 1D6…`（第一段是电缆序号，D 表示电缆）。
- **绕组编号**：`1LHa / 1LHb / 1LHc` —— 呼应一次图里那台 CT 的绕组。
- **装置**：`RCS-941A` 之类保护装置画成**方框**（方框符号，只画端子不画内部）。

## 4. 本轮的简化版范围（第一刀）

**符号（10 个 + 1 个容器）**：常开接点、常闭接点、按钮、切换开关、压板（连接片）、信号灯、
保护装置方框、端子、互感器二次绕组、接地；**端子排**是容器（矩形 + 一列端子，端子是可连线的子图元）。

**图种**：110kV 线路保护电流回路（简化版）—— CT 三个绕组 → 三相电流回路（A411/B411/C411 + N411）
→ 端子排 → 保护装置方框，N 侧接地。

**语义校验（4 条）**：

1. 每条二次导线必须有**回路编号**（error）；
2. 电流回路的三相编号必须成组（同一数字段上 A/B/C 都要有，缺相 error）；
3. 端子号在同一张图上唯一（error）；
4. 二次回路必须有**接地**（warning）。

## 5. 已知限制（本轮刻意不做）

1. **不与一次图联动**：真实工程里二次图要挂到具体间隔上（一次间隔 ↔ 保护装置 ↔ 端子排）。
   本轮先把图种与记法立住，联动下一轮做。
2. **端子排是简化形态**：矩形 + 一列端子（端子可单独连线），还不是真实图纸那种「左侧现场 / 右侧屏柜」的双列排法。
3. **控制回路 / 防跳 / 闭锁**没做：那部分规则更绕，等第一刀验证过记法再上。
4. **智能站虚端子**（GOOSE / SV）没有参考资料，不做。
5. 参考资料是公开教材，**只作记法参考**：本包的符号与示例都是自己画的，不搬运整页图。
